# 通知の設定（Discord / Gmail）

アラートは Discord と Gmail のどちらか、または両方に送れます。**スマホにすぐ届く Discord がおすすめ**です。メールは数十秒～数分遅れることがあります。

設定はすべて `config/secrets.toml` に書きます（`scripts/install.sh` で作成済み）。書いたら次のコマンドでテストします。

```bash
cd ~/baby-monitor
venv/bin/python baby_monitor.py --test-notify
sudo systemctl restart baby-monitor     # 自動起動を登録済みなら、反映のため再起動
```

## Discord

### 1. アカウントとアプリ
- PC：https://discord.com で登録（ブラウザ版で OK）
- スマホ：Discord アプリを入れて同じアカウントでログイン（通知を受け取るのはこちら）

### 2. 見守り用のサーバーを作る
1. 画面左端のアイコン列の一番下の「＋」（サーバーを追加）
2. 「オリジナルの作成」→「自分と友達のため」
3. サーバー名（例：`見守りカメラ`）を入れて「新規作成」

### 3. 通知用のチャンネル
最初からある「#一般」でも OK です。分けたい場合は「テキストチャンネル」横の「＋」→「テキスト」→ 名前（例：`アラート`）→「チャンネルを作成」。

### 4. ウェブフック URL を作る
1. チャンネル名にマウスを乗せ、歯車マーク（チャンネルの編集）
2. 左メニュー「連携サービス」→「ウェブフックを作成」（2回目以降は「ウェブフックを確認」→「新しいウェブフック」）
3. 名前（例：`見守りカメラ`。通知の送り主として表示されます）とチャンネルを確認
4. 「**ウェブフックURLをコピー**」→ 画面下に「変更を保存」が出ていれば押す

URL は `https://discord.com/api/webhooks/数字/英数字の長い文字列` の形です。

> ⚠️ この URL を知っている人は誰でもこのチャンネルに投稿できます。人に見せない・SNS やチャットに貼らないでください。漏れたら同じ画面でウェブフックを削除して作り直します。

### 5. secrets.toml に書く

```toml
[discord]
webhook_url = "https://discord.com/api/webhooks/1234567890/abcdefg..."
```

### 6. スマホで確実に鳴るようにする（重要）
1. Discord アプリで見守りサーバー名を押す →「通知設定」→「**すべてのメッセージ**」。「サーバーをミュート」がオフか確認
2. スマホ本体の設定で Discord の通知を許可（iPhone：設定→通知→Discord ／ Android：設定→アプリ→Discord→通知）
3. **おやすみモード・睡眠モードでも鳴るよう、Discord を例外（許可するアプリ）に追加**。これをしないと夜間のアラートが鳴りません
4. PC で Discord を開いたままだとスマホに通知が来ないことがあります。夜は PC 版を閉じるか、PC 版の「ユーザー設定 → 通知 → プッシュ通知の非アクティブタイムアウト」を「1分」に

### 7. 家族にも届ける
サーバー名 →「招待」でリンクを作って送ります。参加した人にも手順6の設定をしてもらってください。

## Gmail

1. **送信用の Google アカウント**を用意します。普段使いとは別に、見守りカメラ専用の Gmail を作るのがおすすめです（パスワードがラズパイに保存されるため）。
2. そのアカウントで **2段階認証プロセスをオン**にします（Google アカウント → セキュリティ）。
3. Google アカウントの検索欄で「アプリパスワード」を検索し、名前（例：`babycam`）を付けて作成します。表示される **16文字** をメモします（スペースは入っていても入っていなくても OK）。
4. `config/secrets.toml` に書きます。

```toml
[gmail]
user = "babycam.example@gmail.com"
app_password = "abcd efgh ijkl mnop"
to = ["自分のアドレス@gmail.com", "家族のアドレス@example.com"]
```

通常のログインパスワードでは送れません。必ずアプリパスワードを使ってください。

## 通知の種類

| 通知 | タイミング |
|---|---|
| 🔔 テスト通知です | `--test-notify` で起動したとき |
| 見守りカメラを起動しました | 起動したとき（停電からの復帰や再起動に気づける） |
| ⚠️ 顔が○秒間見えていません（写真付き） | 見守り中に顔が見えなくなったとき。見えないままなら2分ごと |
| ✅ 顔が再び見えるようになりました（写真付き） | アラート後に顔が戻ったとき |
| ℹ️ まだ一度も顔を確認できていません | 見守りを始めてから10分、顔を確認できないとき（1回だけ） |
| 🛑 異常停止しました | プログラムが異常終了したとき（自動で再起動します） |

## うまく届かないとき

ログを確認します。

```bash
journalctl -u baby-monitor -n 50      # 自動起動している場合
```

- `Discord通知に失敗: 404` … URL が間違っているか、ウェブフックが削除されている
- `Discord通知に失敗: 401` / `403` … URL の後半が欠けている（コピーし直す）
- `Gmail通知に失敗: (535, ...)` … アプリパスワードが違う、または2段階認証がオフ
- 何も出ない … `secrets.toml` の項目が空になっている
