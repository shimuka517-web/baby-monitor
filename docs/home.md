# 育児ダッシュボード（スマホで外出先からも）

スマホのブラウザで、ミルク・おむつ・部屋の温湿度・天気・体重をまとめて見たり、記録したりできる画面です。
ラズパイの中で動いていて、外出先からは **Tailscale**（無料のVPNアプリ）を通して見ます。インターネットには何も公開しません。

```
http://<ラズパイのIP>:8000/dash      家のWi-Fiから
http://raspberrypi:8000/dash         Tailscale から（家の外でも）
```

## 画面にあるもの
**いちばん上（スマホの最初の1画面）に、ひと目で分かるタイル** が並びます。タイルを押すと、下の詳しい表示に移ります。

| タイル | 内容 |
|---|---|
| ミルク・母乳 | 前回の授乳（あげ始め）からの時間と前回の量。授乳中なら経過時間 |
| おむつ | 前回のおむつ替えからの時間、前回のうんち |
| おへや | SwitchBot ハブ3 の室温・湿度と、ここ数時間の動き。目安の範囲を外れると赤い枠 |
| おそと | いまの外の気温と、今日の天気・最高/最低・降水確率（Open-Meteo） |
| きょう | 今日のミルク合計と回数、おむつの回数（おしっこ・うんち） |
| たいじゅう | 最新の体重と、1日あたりの増え方 |

その下に、**きょうのながれ**（直近24時間に、いつ授乳とおむつ替えをしたかを1本の線で）があり、
スクロールすると、**温湿度の24時間グラフ・体重の推移・3日分の天気・さいきんの記録** が続きます。

### 記録は「＋ きろく」ボタン1か所から
画面の下にいつも出ている **「＋ きろく」** を押すと、記録するものを選べます。
- **ミルク・母乳**：「あげ始める」→ そのまま、ミルク（10ml）と母乳（5ml）の量を入れるパネルに。飲み終わったら「あげ終わった」。開始時刻の±5分、押し忘れたときの「あとからまとめて記録」、記録直後の「取り消す」もここで（ベッド横の画面は、今までどおり大きなミルク画面）
- **おむつ**：いつ替えたか（いま・10分前・30分前・1時間前）を選んで、**おしっこ／うんち／おしっこ＋うんち** を押すだけ。10秒間は取り消し可
- **たいじゅう**：g（グラム）で入れる。同じ日に入れ直すと上書き。消すときは下の「たいじゅうの推移」から
- **見守りカメラ**：カメラの画面へ

範囲を外れると、タイルに **「暑い」「寒い」「乾燥」「じめじめ」** と出て、赤い枠になります（Discord にも通知）。

**設定** は、いちばん下までスクロールしたところにあります（お部屋の「暑い・寒い」通知のオン・オフ）。

右上の「見守り中」などの表示を押すと、カメラの画面に移ります（家のWi-Fiにいるときだけ。下の「カメラは家の中だけ」）。

### 記念日
`[baby] birth_date` を入れておくと、**生後○か月（毎月の誕生日と同じ日）・お七夜（7日目）・100日目（お食い初め）・200日目…・1歳のお誕生日** の日に、上にお祝いの帯が出ます。3日前からは「あと○日で 生後1か月」と小さく出ます。

### 見守りカメラの画面（スマホ用）
ダッシュボードの右上の「見守り中」や、「＋ きろく」→「見守りカメラ」から開く、スマホ専用のカメラ画面（`/cam`）です。
映像・見守りの状態（見守り中／顔を確認中／顔を探しています／一時停止）・「一時停止／見守り開始」・写真（静止画を開いて保存）だけに絞っています。
アラートのときは画面全体が赤くなり、「様子を見ました」ボタンが出ます。映像の右上のボタンで全画面になります。
画面を閉じたりアプリを切り替えたりすると、映像の受信を止めます（電池と通信の節約）。

### カメラは家の中だけ
カメラの映像は、**家のWi-Fi（ラズパイと同じネットワーク）につないだ端末からだけ** 見られます。Tailscale（外出先）からは、ダッシュボードとミルクの記録は使えますが、映像は出ません（ラズパイが映像を送らないので、設定ミスやスマホの紛失があっても映像は外に出ません）。
- 家にいるときは、Tailscale で開いたダッシュボードからでも、ラズパイの家のアドレスに自動でつながるか確かめて、つながればカメラのボタンが使えます
- 外出先では、カメラのボタンが薄くなり「家のWi-Fiで見られます」と出ます
- 見守りの通知（Discord・Gmail の写真つき）は、今までどおり外出先にも届きます
- 外からも映像を見たいときは、`settings.toml` の `[web] camera_lan_only = false` にして再起動
ベッド横の画面では、右上の棒グラフのボタンからこの画面を開けます。

- スマホの「ホーム画面に追加」をすると、アプリのように全画面で開けます（アイコンは赤ちゃんの顔）
- スマホがダークモードなら、落ち着いた暗い色になります
- 30秒ごと、またはアプリを開き直したときに最新になります

## 1. Tailscale を入れる（外出先から見る）
Tailscale は、自分の端末どうしだけをつなぐVPNです。ラズパイのポートをインターネットに開けないので安全です。個人利用は無料です。

### ラズパイ
```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
```
表示されたURLをPCのブラウザで開き、Googleアカウントなどでログインします。

**大事：ラズパイの「キーの期限」を切る。** そのままだと約180日でつながらなくなります。
Tailscale の管理画面（https://login.tailscale.com/admin/machines）→ raspberrypi の「…」→ **Disable key expiry**。

### スマホ（ご自分・家族）
1. App Store / Google Play で **Tailscale** を入れる
2. ラズパイと **同じアカウント** でログインする（家族は、管理画面の Users → Invite で招待して、自分のアカウントで入ってもらうこともできます）
3. Tailscale をオンにして、ブラウザで `http://raspberrypi:8000/dash` を開く → ホーム画面に追加

開けないときは、`raspberrypi` の代わりに Tailscale アプリに出ている `100.` で始まるアドレスを使ってください。
スマホをなくしたときは、管理画面からその端末を削除すれば、もうつながりません。

### （任意）https で開く
管理画面の DNS → HTTPS Certificates をオンにしてから、ラズパイで
```bash
sudo tailscale serve --bg 8000
```
とすると、`https://raspberrypi.<あなたのtailnet名>.ts.net/dash` で開けます（Tailscale の中だけ）。

## 1-2. アプリの通知（見守りアラート・お部屋の暑い・寒い）
ホーム画面に追加したアプリに、ラズパイから直接通知を出せます（Web Push）。ロック画面に出て、タップするとカメラ画面やダッシュボードが開きます。
**アプリを閉じていても、スマホの Tailscale がオフでも届きます**（Apple・Google の通知サーバーを通るため）。

スマホのブラウザは **https のページでしか通知を許可しない** ので、Tailscale で https にします。

1. ラズパイに通知用の部品を入れる（最初の1回）
   ```bash
   cd ~/baby-monitor && venv/bin/pip install -r requirements.txt
   sudo systemctl restart baby-monitor
   ```
2. Tailscale の管理画面 → **DNS** → **HTTPS Certificates** を「Enable」
3. ラズパイで（1回だけ。再起動しても続きます）
   ```bash
   sudo tailscale serve --bg 8000
   ```
   表示された `https://raspberrypi.<あなたのtailnet名>.ts.net/` がアプリのアドレスです
4. スマホ（Tailscale オン）で `https://raspberrypi.<あなたのtailnet名>.ts.net/dash` を開き、**ホーム画面に追加**（前に追加した http のアイコンは消してOK）
5. **ホーム画面のアイコンから開いて**、いちばん下の設定 →「**このスマホで通知を受け取る**」→ 許可
   - iPhone は iOS 16.4 以降で、ホーム画面のアイコンから開いたときだけ使えます
   - 家族のスマホも、それぞれ同じようにします

設定でできること
- このスマホに届ける種類：**見守りアラート**（顔が見えない・見えるようになった）／**お部屋の暑い・寒い**
- **Discord にも送る**：見守りアラート・お部屋の暑い・寒いを、それぞれ Discord にも送るか（アプリだけにしたいときはオフ）
- 起動・カメラが見つからない・異常停止などのお知らせは、これまでどおり Discord に届きます
- 見守りアラートの通知は、触るまで消えません

https のアプリから開いても、**家のWi-Fiにいるときはカメラが見られます**（Tailscale の通り道が家のLANの直接接続になっているかで判断します）。外出先では映像は出ません。

## 2. 部屋の温湿度（SwitchBot ハブ3）
1. SwitchBot アプリで、ハブ3の設定の **クラウドサービス** がオンになっているか確認
2. アプリの **プロフィール → 設定（プリファレンス）→ アプリについて → アプリバージョン** を10回ほど続けてタップ → **開発者向けオプション** が出る
3. **トークン** と **クライアントシークレット** をコピー（パスワードと同じ扱い。人に見せない・チャットに貼らない）
4. ラズパイで設定ファイルに書く
   ```bash
   nano ~/baby-monitor/config/secrets.toml
   ```
   ```toml
   [switchbot]
   token = "コピーしたトークン"
   secret = "コピーしたクライアントシークレット"
   ```
5. `sudo systemctl restart baby-monitor` → `journalctl -u baby-monitor -n 30` に「温湿度の取得元: ハブ3」と出ればOK

取得は5分ごと（1日288回。SwitchBot API の上限 1日10,000回 に十分おさまります）。
温湿度計を別に持っていて、そちらを使いたいときは `settings.toml` の `[env] device_id` にその機器のIDを書きます。
アプリでログインし直すとトークンが変わることがあります。取得できなくなったら、新しいトークンを入れ直してください。

### 目安の範囲と通知
`config/settings.toml` の `[env]`（保存すると自動で反映）
| 項目 | 既定 | 内容 |
|---|---|---|
| `temp_min` / `temp_max` | 20 / 23 | 室温の目安（℃）。新生児の冬の目安。夏は 25〜28℃ が目安とされることが多いので、季節で変えてください |
| `hum_min` / `hum_max` | 40 / 60 | 湿度の目安（%） |
| `alert` | true | 範囲を外れたら Discord に通知（範囲に戻ったときも1回）。ダッシュボードのいちばん下の「設定」からもオン・オフできます |

範囲の値は一般的な目安です。季節やかかりつけの先生の話に合わせて変えてください。境目で何度も鳴らないよう、室温は0.5℃・湿度は3%内側に戻るまで「戻った」とはしません。

## 3. 名前・誕生日・天気の場所
`config/settings.toml`
```toml
[baby]
name = ""                 # 画面の左上に出る名前（空なら「育児の記録」）
birth_date = "2026-11-14" # 「生後○日」の表示

[weather]
latitude = 36.314
longitude = 139.800
place = "小山市"
```
`[baby]` と `[env]` は保存すると反映されます。`[weather]` を変えたときは再起動してください。

## 4. スプレッドシート
ミルクと同じシートに、**おむつ・体重・室温** のタブが自動でできます（室温は1時間ごとの平均）。Muse からも読めます。
そのために、Apps Script を新しい `gas/milk_sheet.gs` に貼り直してください（手順は docs/milk.md「v2.5 以前から更新するとき」と同じ。TOKEN の行は今のものに戻す → 新しいバージョンでデプロイ）。
今回の Apps Script は、表の名前と見出しを受け取って自動で作るので、今後記録の種類が増えても貼り直しは不要です。

貼り直すまでの記録はラズパイ内にたまり、貼り直したあとに自動で送られます。

| タブ | 列 |
|---|---|
| おむつ | 日時・種類（おしっこ／うんち／おしっこ＋うんち）・記録した場所・ID |
| 体重 | 日付・体重(g)・メモ・ID |
| 室温 | 日時（その1時間の始まり）・室温(℃)・湿度(%)・ID |

## しくみ
| どこ | 役割 |
|---|---|
| `logbook.py` | おむつ・体重の記録、温湿度の履歴（`data/logbook.db`、温湿度は30日分）、シートへの送信待ちの列 |
| `home_env.py` | SwitchBot API（署名つき）から温湿度を取得・範囲外の通知、Open-Meteo から天気 |

| `web/cam.html` | スマホ用の見守りカメラ画面（映像は家のLANのアドレスから直接読み込む） |
| API | `GET /api/dash`、`POST /api/diaper` `/api/diaper/undo` `/api/weight` `/api/weight/delete` |
