# 毎日の使い方と役割分担

## 使う人の役割

| 役割 | やること |
|---|---|
| 管理する人（設置した人） | セットアップ、設定の調整、月1回の動作テスト、困ったときの対応。ラズパイに SSH で入れる人 |
| 見守る家族 | 寝かせたあとに「見守り中」になったか確認する、アラートが来たら様子を見に行く、抱っこ中は一時停止する |

見守る家族は、ブラウザと Discord（またはメール）だけ使えれば十分です。ラズパイの操作は必要ありません。

---

## 寝かせるとき・起きたとき

1. 寝かせたら、ブラウザ（`http://<ラズパイのIP>:8000/`）で表示を確認します。
   - 黄「**顔の確認待ち（○/10秒）**」→ 10秒ほどで緑の「**見守り中・顔OK**」に変われば OK
   - 確認待ちのまま進まないときは、顔がカメラに映っているか（向き・布団・暗さ）を確認してください。**確認待ちの間は、顔が見えなくてもアラートは出ません。**
2. 抱っこ・授乳・おむつ替えなどで寝床から離すときは「**一時停止**」を押します（誤報防止）。
3. 寝床に戻したら「**見守り開始**」を押します。再び「確認待ち」から始まります。

一時停止にし忘れても、アラートが来るだけで害はありません。逆に「見守り開始」の押し忘れには注意してください。

## 画面の見方

右側の大きなカードの色で、いまの状態が分かります。

| 表示 | 意味 |
|---|---|
| 灰「一時停止中」 | 見守っていない（通知しない）。「見守り開始」で始まる |
| 黄「顔を確認中 ○/10秒」 | 顔を確認中。まだアラートは出ない |
| 緑「見守り中」 | 見守り中で、顔が見えている。「見守り開始から」の時間も出る |
| 橙「顔を探しています」 | 見失っている。「あと○秒で通知します」が0になるとアラート |
| 画面全体が赤「アラート」 | 通知済み。顔が3秒見えると自動で解除 |
| 灰「カメラが見つかりません」 | カメラのケーブルを確認。見つかり次第、自動で始まる |
| 灰「通信できません」 | ラズパイのプログラムにつながらない（電源・Wi-Fi・プログラム停止） |

映像の枠：緑＝顔を検出中、赤＝見失った位置。

### ボタン
- **ミルク**：ミルクの記録（[milk.md](milk.md)）。ボタンに「前回 ○時間○分前・○ml」が出ます
- **一時停止／見守り開始**
- **頭の向き**：赤ちゃんの頭がカメラ側か反対側かで、映像を上下に回します
- **明るさ**（ベッド横の画面だけ）：消す／暗い／ふつう／明るい と、＋−で10%ずつ。いまが夜なら夜の明るさ、昼なら昼の明るさとして覚えます。「消す」を選ぶと、画面に触れるまで消えます
- **歯車（設定）**：頭の向き・お知らせまでの時間（10/15/30秒）・夜の画面・通知の状態とテスト通知

### 夜の画面
21:00〜7:00 は、ベッド横の画面が「夜の画面」（暗い時計と状態だけ）になります。画面に触れると30秒間ふだんの画面に戻ります。
設定の「夜の画面」で「暗くする／消す／そのまま」を選べます。**アラートのときは、夜でも画面が明るくなります。**
時間帯は `config/settings.toml` の `[display]`（`night_start` / `night_end`）で変えられます。

画面の設定で変えた値は `data/ui.json` に保存され、`settings.toml` の同じ項目より優先されます。

## アラートが来たら

1. **まず実際に様子を見に行ってください。** 通知の写真は、アラートが出た瞬間のものです。
2. 様子を見たら、画面の「**様子を見ました**」を押します。再通知（2分ごと）が止まり、顔が見えると自動で見守りに戻ります。
3. 顔が戻れば、3秒後に「復帰」の通知が来ます。
4. 誤報だった場合は、原因（布団で顔が隠れた、寝返りで横を向いた、暗かった など）をメモしておくと、管理する人が設定を調整できます（[tuning.md](tuning.md)）。

## 「異常停止しました」「起動しました」が突然来たら

- 「異常停止しました」：プログラムが落ちましたが、5秒後に自動で再起動します。続けて「起動しました」が来れば復旧しています。何度も繰り返す場合は管理する人がログを確認してください。
- 「起動しました」だけが来た：停電やコンセントが抜けた後に再起動した可能性があります。

## ラズパイの画面に全画面で出す（起動時に自動）
ベッド横の画面（8インチのタッチ液晶など）に、電源を入れたら見守り画面が全画面で出るようにできます。
```bash
cd ~/baby-monitor && bash scripts/install-kiosk.sh
sudo reboot
```
- 前提：デスクトップ版の Raspberry Pi OS で、自動ログインが有効なこと（`sudo raspi-config` → System Options → Boot / Auto Login → Desktop Autologin）
- 全画面を抜けるとき：キーボードで Alt+F4、または SSH で `pkill -f chromium`
- 解除：`bash scripts/install-kiosk.sh --remove`
- ブラウザで自分で開くときは、`http://localhost:8000/` のように **`http://` から**入力してください（`https://` になると表示できません）

## 設置後に必ずやるテスト

設置したとき、カメラの位置を変えたとき、設定を変えたときに行います。**できれば月1回**、定期的に行ってください。

1. 人形や大人の顔を寝床に置き、表示が「確認待ち」から「見守り中」（緑）に変わる
2. 顔を布で隠す／うつ伏せにして、15秒後にスマホにアラートが届く（**スマホの音が鳴ることまで確認**）
3. 顔を戻して、3秒後に「復帰」の通知が届く
4. 夜（部屋を暗くして赤外線ライトを点けた状態）でも同じことを確認
5. スマホをおやすみモードにした状態でも鳴ることを確認

## 設置のコツ

- カメラは寝床の**真上～斜め上**から、顔が大きめに映る位置に。
- **カメラ・ケーブルは赤ちゃんの手が絶対に届かない位置に固定**。ケーブルはたるませず、寝床に垂らさない。
- 窓からの直射日光やライトが直接映り込むと、検出しにくくなります。
- 柄の多い布団やぬいぐるみは誤検出の原因になります。緑の枠が顔以外に出ていないか確認してください。

## 安全についての大事な前提

これは自作の補助ツールで、医療機器ではありません。顔が見えているかどうかしか見ておらず、呼吸や体調は分かりません。見逃しも誤報も起こります。安全な寝かせ方（仰向け寝・固めの寝具・顔まわりに柔らかい物を置かない）と、大人による見守りを前提に使ってください。
