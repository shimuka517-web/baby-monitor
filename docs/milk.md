# ミルクの記録

ベッド横の画面（またはスマホのブラウザ）から、ミルクをあげた量と時刻を記録します。
記録はラズパイ本体に保存され、設定すれば Googleスプレッドシートにも自動で送られます。家族のスマホや Meta の Muse などのAIからも、シートを見れば最新の記録が分かります。

## 使い方

1. メイン画面の **「ミルク」** ボタンを押す（ボタンには「前回 ○時間○分前・○ml」が出ています）
2. **＋ / −** ボタン（1回10ml）か、よく使う量のボタンで量を合わせる
   - 画面を開いたときは、前回と同じ量になっています
3. **「○ml を記録する」** を押す → その時刻で記録されます
4. 押し間違えたときは、直後の画面の **「取り消す」**（10秒間）を押す
   - 時間がたった記録は、スプレッドシートで直接直してください（下の「記録を直したいとき」）

画面の右側には、前回からの時間・今日の合計と回数・今日の記録が出ます。
スマホからは `http://<ラズパイのIP>:8000/milk` を開けば同じ画面が使えます（ホーム画面に追加しておくと便利）。

## しくみ

| どこ | 役割 |
|---|---|
| `milk.py` | 記録・取り消し・集計と、スプレッドシートへの送信。記録はまず `data/milk.db`（ラズパイ内）に保存 |
| `web/milk.html` | 記録画面 |
| `gas/milk_sheet.gs` | スプレッドシート側の受け口（Google Apps Script） |
| `config/settings.toml` の `[milk]` | ボタンの量や取り消しの秒数（保存すると自動反映） |
| `config/secrets.toml` の `[sheets]` | 送り先のURLと合言葉 |

- **ネットが切れていても記録は失われません。** ラズパイ内に保存しておき、つながったら古い順に送ります（1分ごとに再送）。
- シートに送る前に取り消した記録は、シートには送りません。送った後に取り消した場合は、シートの行も消します。
- 同じ記録が二重に届いても、シートには1行だけ入ります（ID で判定）。

## スプレッドシートの準備（最初に1回）

### 1. スプレッドシートを作る
Googleドライブで新しいスプレッドシートを作り、名前を付けます（例：`赤ちゃんの記録`）。Muse に見てもらうときは、このファイル名を伝えます。

### 2. Apps Script を貼り付ける
1. スプレッドシートのメニュー **「拡張機能 → Apps Script」** を開く
2. 最初からある中身を消して、`gas/milk_sheet.gs` の中身をすべて貼り付ける
3. 先頭の `const TOKEN = '…'` を、**自分だけの合言葉**（英数字20文字以上がおすすめ）に書き換えて保存
4. 上の関数の選択欄で **`setup`** を選んで「実行」
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します（「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）
   - シートに「ミルク」「日別まとめ」のタブができれば成功です

### 3. ウェブアプリとして公開する
1. 右上の **「デプロイ → 新しいデプロイ」**
2. 種類の歯車から **「ウェブアプリ」** を選ぶ
3. **次のユーザーとして実行：自分** ／ **アクセスできるユーザー：全員**
4. 「デプロイ」を押し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

「全員」にしても、合言葉を知らない人は書き込めません。URLと合言葉は人に見せないでください。

### 4. ラズパイに設定する
```bash
nano ~/baby-monitor/config/secrets.toml
```
```toml
[sheets]
gas_url = "https://script.google.com/macros/s/xxxxxxxx/exec"
token = "手順2で決めた合言葉"
```
```bash
sudo systemctl restart baby-monitor
journalctl -u baby-monitor -n 20     # 「ミルク記録: スプレッドシートへ送信します」と出ればOK
```

### 5. 動作確認
1. 画面からミルクを1件記録 → 1分以内にシートの「ミルク」タブに1行増える
2. 「取り消す」を押す → その行が消える
3. Muse に「（ファイル名）の最新のミルクの記録を教えて」と聞いてみる

## 記録を直したいとき
スプレッドシートの「ミルク」タブで、行を直接直したり消したりしてください。
ただし、ラズパイ内の記録（画面の「前回から」「今日の合計」）は変わりません。画面の表示まで直したい場合は、ラズパイで次のように消せます（IDはシートのE列）。

```bash
sqlite3 ~/baby-monitor/data/milk.db "UPDATE feeds SET deleted=1, synced_del=1 WHERE id='（ID）';"
```
（`sqlite3` がなければ `sudo apt install -y sqlite3`）

## 設定（config/settings.toml の [milk]）
| 項目 | 既定 | 内容 |
|---|---|---|
| `default_ml` | 100 | 記録がまだないときに、画面を開いたときの量 |
| `step_ml` | 10 | ＋・−ボタン1回で変わる量 |
| `max_ml` | 300 | 記録できる最大の量 |
| `presets` | 40,60,80,100,120,160 | ワンタッチで選べる量（6個がちょうど並びます） |
| `undo_sec` | 10 | 記録した直後に「取り消す」を押せる秒数 |

## うまくいかないとき
| 症状 | 確認すること |
|---|---|
| 画面に「共有シートへ未送信 ○件」と出続ける | `journalctl -u baby-monitor -n 50` の「スプレッドシートへの送信に失敗」の内容を見る |
| 「合言葉（token）が違います」 | `secrets.toml` の token と、Apps Script の `TOKEN` が同じか |
| 「Apps Script の応答が読めません」 | URLが `/exec` で終わっているか。デプロイの「アクセスできるユーザー」が「全員」か |
| Apps Script を書き換えたのに反映されない | 「デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新しいバージョン」で更新する（URLは変わりません） |
| 画面に「ラズパイ内に保存中（共有シートは未設定）」 | `secrets.toml` の `[sheets]` が空のまま。設定後に再起動 |

## データの置き場所とバックアップ
- ラズパイ内：`~/baby-monitor/data/milk.db`（GitHubには上がりません）
- スプレッドシートが実質のバックアップになります。ラズパイのSDカードが壊れても、シートの記録は残ります。
